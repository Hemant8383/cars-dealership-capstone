# Cars Dealership

**Repository Name:** cars-dealership-capstone

**Project Name:** Cars Dealership

## Project Description
Cars Dealership is a full-stack web application that allows users to explore car dealerships, view dealer details, register and log in, and submit reviews.

## Main Features
- View all car dealerships.
- Search dealerships by state.
- View dealer details and customer reviews.
- Register and log in as a user.
- Submit dealership reviews.
- Analyze customer reviews using sentiment analysis.

## Technologies
- Frontend: React, HTML, CSS, JavaScript
- Backend: Django, Python
- Database: SQLite / MongoDB
- Deployment: Docker, Kubernetes, IBM Cloud Code Engine
- CI/CD: GitHub Actions
