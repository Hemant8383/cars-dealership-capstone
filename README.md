# fullstack_developer_capstone

**Repository Name:** `cars-dealership-capstone`

**Project Name:** `fullstack_developer_capstone`

## Project Description
This project is a full-stack car dealership application developed as part of the IBM Full Stack Software Developer Capstone Project.

The application uses Django for the backend and React for the frontend. It supports viewing car dealerships, user registration and login, and submitting dealership reviews.

## Technologies Used
- Python
- Django
- React
- JavaScript
- REST APIs
- Git and GitHub
